# Pilot test checklist (before sharing widely)

Test on **one iPhone, one iPad and one Android phone**, then ask 5–10 nurses to use it for two weeks.

## On each device
- [ ] Open the link → install (iPhone/iPad: Safari → Share → Add to Home Screen; Android: Chrome → ⋮ → Install app)
- [ ] Open from the home-screen icon; the icon and name look right
- [ ] Complete the welcome steps and profile (try RN + midwife, then NP, and check the hour targets)
- [ ] Log an activity with a quick-start template
- [ ] **Photo / scan** a real certificate: camera opens, rotate and document mode work, thumbnail opens in the viewer
- [ ] Upload a PDF certificate and 2+ photos at once
- [ ] Guided reflection fills the reflection box
- [ ] Study timer: start, close the app, reopen 20 min later, stop & log
- [ ] Add practice hours and check the recency bar
- [ ] Print / PDF portfolio, and Save as file (open the file and print it from Safari/Chrome)
- [ ] Print / PDF resume
- [ ] Back up everything → save to Files / Drive → delete all data → restore → records and certificates are back
- [ ] Turn on airplane mode and reopen the app (should work offline)
- [ ] Dark mode looks right
- [ ] (Optional) AI: add a key, test, draft a reflection, read a certificate

## Ask pilot nurses
1. What confused you?
2. What did you want to log but couldn't?
3. Would you use it instead of what you use now? Why / why not?
4. Did anything break or lose data?
